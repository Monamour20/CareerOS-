# CareerOS

CareerOS is an AI-first career platform. The first implemented service is the AI Service, which converts uploaded resumes into a structured career profile.

Initial scope:

- Universal resume file upload
- Document text extraction
- OCR for image resumes and scanned PDFs
- Ollama-backed resume analysis
- Strict `CareerProfile` validation

See [services/ai-service/README.md](services/ai-service/README.md) for setup and usage.
