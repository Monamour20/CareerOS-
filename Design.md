# CareerOS — Design System

## Design Direction
Premium professional operating system rather than generic AI chatbot.

Keywords:
- Clean
- Modern
- Premium
- Professional
- Calm
- Data-focused
- AI-native without excessive visual effects

Use the provided visual reference as inspiration, not as a pixel-for-pixel copy.

## Navigation
Potential primary areas:
- Overview
- Career Vault
- Opportunities
- Resume Studio
- Applications
- Interviews
- Networking
- Analytics
- Settings

## Dashboard
Surface:
- Career health
- Recommended next action
- Top opportunities
- Skill gaps
- Application status
- Upcoming interviews
- Recent AI insights

Avoid a wall of charts/cards.

## Career Vault
Sections:
Personal, Education, Experience, Skills, Projects, Certifications, Achievements, Goals, Preferences, Resumes.

AI-extracted items must be editable.

## Opportunity UI
Show role, company, location, match score, why it matches, missing requirements, recommended action, Save/Reject/Interested.

## Resume Studio
Use `Editor | Preview`.

Controls:
Template, typography, accent, section order, spacing, AI suggestions, JD tailoring, ATS analysis.

## Theme
Use centralized design tokens. Support light/dark themes and accessible contrast.

## Motion
Use subtle transitions and processing states. Do not let animation slow productive workflows.

## Accessibility
Semantic HTML, keyboard navigation, visible focus, labels, accessible dialogs, sufficient contrast, clear errors.

## AI UX
Never expose hidden model reasoning. Show useful status messages such as:
- Reading resume
- Extracting career information
- Checking profile
- Analyzing opportunity
- Preparing application
- Waiting for approval
